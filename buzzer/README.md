# 🔔 باصرة المسابقات (Quiz Buzzer)

تطبيق باصرة لحظي للمسابقات: كل لاعب يدخل من موبايله، والمضيف يجهّز الباصرة، وأول من يضغط
يظهر في الترتيب — والعدالة محسومة من **ساعة السيرفر** مش من سرعة نت اللاعب.

## الصفحات
- `index.html` — صفحة بداية لاختيار الدور (مضيف / لاعب).
- `host.html` — شاشة المضيف: إنشاء غرفة، عرض الأسئلة، تجهيز/قفل الباصرة، الترتيب اللحظي، النقاط.
- `player.html` — شاشة اللاعب: الانضمام بالكود، زرار الباصرة، صوت + اهتزاز، عرض الترتيب والنقاط.

## طريقة الاستخدام
1. المضيف يفتح `host.html` ويضغط **"أنشئ غرفة"** → يظهر كود من 4 حروف.
2. كل لاعب يفتح `player.html` على موبايله، يكتب اسمه + الكود، ويضغط **ادخل**.
3. المضيف يكتب السؤال ويضغط **"جهّز الباصرة (جولة جديدة)"** → يولّع زرار اللاعبين.
4. أول ما اللاعبون يضغطوا، يظهر الترتيب (1، 2، 3...) مع فرق التوقيت عند المضيف.
5. المضيف يدّي/يخصم نقاط من لوحة النقاط، وكل لاعب يشوف نقاطه لحظياً.

## التقنية
- HTML/JS عادي (ES modules + CDN) بدون build step.
- [Supabase](https://supabase.com) للتزامن اللحظي (Realtime) وتخزين الحالة.
- مكتبة Supabase تُحمّل وقت التشغيل عبر `esm.sh`.

## الإعداد
- إعدادات الاتصال في `js/config.js` (رابط المشروع + المفتاح العام publishable).
- مخطط قاعدة البيانات: جداول `rooms` / `players` / `buzzes` مع Realtime مفعّل.

## ملاحظة أمنية
سياسات RLS الحالية سمحة (anon يقدر يقرأ/يكتب داخل التطبيق) — مناسب للعبة فرح غير حساسة.
لو احتجنا تشديد لاحقاً، نقيّد العمليات بالـ `room_id` أو نضيف توثيق للمضيف.
